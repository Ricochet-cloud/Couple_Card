## 주요 경험

### 카드 CSS 수정 (2026-10-04)
- 사진이 텍스트를 덮는 문제 해결
- `.card__photo img`: `position: absolute; inset: 0`으로 정확한 위치 조정
- `.card__body`: `overflow: hidden` 추가로 텍스트 잘림 방지

### 뽑기권 동시 접속 문제 (2026-10-04)
- 여러 사용자가 동시에 접속해도 1장만 지급되도록 `runTransaction` 사용
- `lastGrantDate`로 하루 1회만 지급 보장

### 등급 별 카드 확률 (2026-10-04)
- 등급을 먼저 추첨 (가중치) → 해당 등급 카드 중 균등 랜덤
- 해당 등급에 카드 없으면 자동으로 가중치 재계산
