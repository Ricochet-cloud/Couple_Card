# 스프라이트 커터 (tools/sprite-cutter.html)

GPT가 만든 캐릭터 격자 이미지(마젠타 등 단색 배경)를 게임용 스프라이트 시트(64×64 × 7프레임 = 448×64)로 변환합니다.
설치가 필요 없고, 이미지는 브라우저 안에서만 처리됩니다.

## 사용법
1. `tools/sprite-cutter.html` 을 더블클릭해서 브라우저(Chrome/Edge)로 연다.
2. GPT 이미지를 끌어다 놓는다. (기본 4×2 격자, 7프레임)
3. 빨간 격자선과 결과 시트, 달리기 미리보기를 확인한다. 노란 ▲ 경고가 있으면 설정을 조정한다.
4. `PNG 다운로드` → `assets/player/characters/` 에 저장.
5. 화면 아래 코드 조각을 `config/characters.config.js` 의 `CHARACTERS` 배열에 붙여넣는다.

## 자동으로 해주는 것
- 단색 배경 제거 (마젠타 자동 / 직접 고른 색 / 이미 투명한 PNG), 가장자리 분홍 테두리 정리, 잡티 제거
- 칸마다 캐릭터 영역 자동 검출
- 모든 프레임에 같은 배율 적용 (달리기 포즈 높이를 48px에 맞춤)
- 발 위치를 모든 프레임에서 같은 기준선(61행)에 정렬, 가로 중심은 몸통 무게중심에 정렬
- 도트가 뭉개지지 않도록 외곽선 선명하게 처리
