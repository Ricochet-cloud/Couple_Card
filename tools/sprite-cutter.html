Gogun-Run 스프라이트 커터

GPT가 만든 캐릭터 격자 이미지(단색 배경)를 게임용 스프라이트 시트(64×64 프레임 × 7장 = 448×64)로 자동 변환합니다. 이미지는 브라우저 안에서만 처리되며 어디에도 업로드되지 않습니다.

1. 이미지 불러오기

여기에 이미지를 끌어다 놓거나 클릭
PNG / JPG / WEBP

아직 불러온 이미지가 없습니다.

2. 격자 / 프레임

프레임 순서: 달리기 4장 → 점프 → 착지 → 사망. 칸 순서가 다르면 번호를 바꿔 적으세요. (예: 0,1,2,3,5,4,6)

3. 배경 제거

4. 출력 규격

기본값은 현재 탄지로 시트와 같은 규격입니다. 바꾸면 SPRITE_OVERRIDES가 필요할 수 있어요.

원본 (격자 확인)

빨간 선이 칸 경계입니다. 캐릭터가 선에 걸리지 않게 칸 수를 맞춰주세요.
